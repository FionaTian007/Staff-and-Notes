# Staff & Notes · 谱间

**把音符，读成自己的风景。**

欢迎来到这间小小的五线谱练习室。这里没有倒计时，也不用先背完一整本乐理书。你可以点一个音、听听它，再看看它住在五线谱的哪里。每天认识一点点，就很好。

## 先把小教室打开

1. 打开仓库里的 [pujian-music-lab.html](./pujian-music-lab.html)。
2. 点击文件页面右上方的 **Download raw file（下载原始文件）** 按钮，保存 HTML。也可以从仓库的 **Code → Download ZIP** 下载后解压。
3. 用浏览器打开 `pujian-music-lab.html`，就可以开始了。电脑上双击文件通常即可；手机上如果只显示预览，请选择用浏览器打开。

不需要安装软件、注册账号或运行命令。整个练习室装在这一个 HTML 文件里，下载后断网也能玩。GitHub 的代码预览不会运行页面里的交互，请先下载哦。

## 第一次来，给自己五分钟

**第一分钟：随便点点。** 在「探索谱面」里点一个音符，再点琴键，观察右侧的音名与位置提示。试试把「显示音名」关掉，看看还能不能找到刚才的音。

**接下来两分钟：认识三个邻居。** 去「记忆地图」看看中央 C、高音 G、低音 F。先认出一个地标，再顺着线和间往上、往下找，不必每次都从头背。

**最后两分钟：来一轮小练习。** 打开「认音练习」，选「地标起步」。每轮十题，不限时；想不起来就点「给我一个地标」。答错或用过提示的音，会进入「易错音口袋」，以后再见面。

做到这里就可以休息了。明天回来，再多认识几个音。

## 今天想玩哪一页？

| 章节 | 可以试试的小动作 |
| --- | --- |
| 探索谱面 | 切换高音、低音谱号，点击谱面和钢琴，让位置与声音连起来。 |
| 记忆地图 | 从三个地标出发；听相邻音、隔音与八度，还能比较 G 在不同大调里的唱名。 |
| 符号图鉴 | 搜索「附点」「升号」等关键词；点开卡片查看含义、记忆提示，部分符号可以试听。 |
| 节奏工坊 | 把音符和休止符拼成一小节，调慢速度，跟着节拍听；再读一段《小星星》。 |
| 认音练习 | 从地标逐渐挑战高音、低音和混合谱表，回头专练易错音。 |

页面下方的彩色卡片也能带你跳到对应章节。没有规定必须走哪条路线，好奇哪个，就先打开哪个。

## 几个让练习更顺手的小提示

- **没有声音？** 先点一下音符或播放按钮。浏览器通常要等你第一次点击才允许发声。再检查页面右上角静音、音量，以及设备和浏览器的声音设置。
- **手机上谱面没显示全？** 在谱面或琴键区域左右滑动；章节导航也可以横向滑动。
- **想用键盘？** 章节标签获得焦点后，用左右方向键切换；认音时按 A–G 作答、Enter 进入下一题；Esc 关闭符号详情。
- **进度在哪里？** 练习统计保存在当前浏览器本地，不上传。换设备、换浏览器、移动本地文件或清理浏览器数据，记录可能不会保留；在线版和下载版也不共享进度。本地存储不可用时仍能练习。
- **想重新开始？** 页面底部有「重置练习记录」，清空前会请你确认。

## 一点点学习约定

本页用 C–D–E–F–G–A–B 表示音名，中央 C 记为 C4。声音是合成音色，以 A4 = 440 Hz 为基准，主要用来听清音高和时值。唱名与音名的区别，可以在「记忆地图」里慢慢探索。

学习参考链接和符号字体说明都保留在页面底部的「学习约定、参考资料与使用说明」。只有主动打开这些外部资料时，才需要联网。部分音乐符号使用 Noto Music 的矢量轮廓，字体版权归 The Noto Project Authors，按 SIL Open Font License 1.1 使用。

仓库已经带有 `index.html` 入口。仓库所有者可在 **Settings → Pages** 中选择 **Deploy from a branch → main → / (root)** 并保存。等待 GitHub 显示部署成功后，以该页面给出的地址访问；提交文件到仓库本身并不代表 Pages 已开启。
