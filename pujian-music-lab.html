2.

线、间轮流走，音名依次向前

相邻位置按 C–D–E–F–G–A–B 循环。B 再往上就是下一个 C；上下相邻的位置，音高距离可能是半音或全音。

3.

先看谱号，再给音符命名

高音谱号把第二线定为 G4；低音谱号把第四线定为 F3。同样的五条线，有了谱号才有音高坐标。

音名 C、具体音高 C4、唱名 do，怎么分清？

C 是音名；C4 把八度也说清楚；do 是唱名。C3 和 C4 都属于 C，相差一个八度。本页用“中央 C = C4”的编号法，数字在 B 走到下一个 C 时增加。[2]

唱名有两种常见体系：固定唱名把 C 唱作 do、G 唱作 sol；首调唱名按调中的角色来唱，大调主音唱 do。因此，G 大调里 G 可以唱 do。“记忆地图”里可以切换 C / G 大调，亲手试一遍。[3]

现在试试：关掉音名，还能找到 G4 吗？

先认三个地标，再慢慢走远。

把少数位置记牢，再沿着线与间找到邻居。熟悉以后，就能直接认出整片区域。[1]

为什么白键之间，有时夹着黑键，有时没有？
键盘上相邻的键（包括黑键）相差半音。E–F、B–C 之间直接相邻；C–D 等相邻白键之间隔了一个黑键，相差全音。谱面上每挪一个相邻位置，走的是下一个字母音名。大调的音高距离依次为“全、全、半、全、全、全、半”，G 大调用 F♯ 来维持这个规律。[3][4]
